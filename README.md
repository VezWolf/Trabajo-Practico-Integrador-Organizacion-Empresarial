Descripción del sistema:

El presente proyecto consiste en el análisis organizacional y el desarrollo de una propuesta de mejora para la empresa Havanna.

A lo largo del trabajo se abordarán diferentes aspectos de la organización, incluyendo Misión, Visión, Mercado, Modelo del Sistema, Ambiente/Contexto, Interdependencia de módulos, Propuesta, Análisis FODA, Objetivos Generales, Metas, diagrama de Gantt, organigrama Piramidal Vertical, Diccionario de Datos y Diagrama de BPMN 2.0.

Como eje principal del proyecto, se propone el diseño y desarrollo de un módulo de software orientado a la fidelización de clientes, con el objetivo de fortalecer la relación con los consumidores, aumentar las ventas, mejorar su experiencia y promover su continuidad como clientes de la empresa.
